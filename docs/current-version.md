## 数据与能力

| 能力 | 实现与限制 |
| --- | --- |
| 数据集、样本、发布版本、历史报告 | 后端 API 与 SQLite 持久化。仓库不包含原电脑的数据库 |
| 任务执行 | FastAPI + Celery + Redis。默认被测目标是确定性贷款 Demo，而不是生产智能体 |
| A/B 实验 | 使用相同发布版评测集与明确的评估器版本；暂按整个发布版本执行，不支持指定用例子集 |
| A/B 数据集选择 | 展示未归档评测集名称；草稿提示发布后使用；已删除“查看 vN 用例”跳转 |
| 联调导入规则 | 实验选择列表排除“联调导入规则 + 时间戳”的自动化测试条目，不删除历史引用 |
| Skill 静态分析 | 后端模型对比 Skill 职责描述，报告可能部分失败；保留问题、建议、依据和人工复核；已移除“选择验证用例”入口 |
| 中文历史报告 | 已补齐当前旧方案和修复方案历史报告的对应中文译文；原始数据保留；未知自由文本不保证自动翻译 |
| 调优中心 | 前端根据后端失败检查项归类并显示规则建议；当前无模型补充分析入口 |
| 人工备注回写 | 后端 writeback 接口写入来源评测集草稿，保留原始检查约束 |
| 内置评估器禁用 | 浏览器本地偏好，不是服务端全局禁用；自定义评估器使用后端接口 |
| Mock 评估器卡片 | 显式标注的配置和输出演示，不参与真实任务评测 |
| 稳定性重复执行 | 当前后端 LaunchRequest 未声明 repetitions；不要将前端相关展示视为已完成接口对齐 |
| 评估器详情 | 保留推荐理由、检查内容、读取内容和源码；已移除使用场景及配置与版本页签等冗余内容 |

## 整理原则

- 保持 frontend/ 与仓库根目录后端的相对位置：前端源码展示使用相邻根目录 src/ 的 Python 文件。
- 保留源码、测试、锁文件及上游许可证，不携带嵌套 .git、虚拟环境、node_modules、构建产物。
- 不公开用户历史数据、密钥、截图、个人工作记录或旧的交付压缩包。
- 提供独立启动入口与示例环境配置；不承诺完全免依赖、离线或打包应用式启动。
- 这是当前 UI 工作版本的源码交付，不代表全部历史端到端测试均已适配新界面。
