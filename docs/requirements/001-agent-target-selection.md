# 需求 001：评测对象选择

状态：本地实现及端到端验证完成，可验收。用户已授权自主完成后续步骤；尚未提交、推送或合并。

## 已确认需求

- 新建测评任务的单任务路径使用新评测对象选择；A/B 保留现有行为。
- 标签“请填写token”，最多 512 字符。登录后明文只读，取消登录清空凭据与关联选择。
- 控件顺序：团队与类型同排、智能体整排、branchId 与智能体版本同排。
- 类型分组为 base/workflow、abcclaw。团队、智能体、版本、分支分别按平台文档接口 3、4、2、5、6 查询。
- base/workflow 不要求分支；abcclaw 使用接口返回的 branchId，并按该分支查询版本。
- 保持工作流已有创建实例契约：agentId + agentVersion，沿用 taskId 查询参数，不增加 branchId。
- 本期最终需处理创建运行、数据集及执行参数的耦合；对象切换不得覆盖用户已选数据集与执行设置，对端 teamId 不改变平台用户团队上下文。
- 本地模拟执行闭环已批准：目标输出可模拟，平台任务创建、评估、存储及结果展示真实执行。不得宣称本地模拟已经验证行内环境。

## 首个组件批准边界

`frontend/src/views/evaluation/components/AgentTargetPicker.vue` 管理对象选择及临时登录态，向父表单提供完整目标或 null。父表单提交时单独读取目标副本及临时 Token，普通选择事件不传播 Token。

用户另行批准显式传入目录查询能力：`directory`。组件接收完整、规范化的列表；HTTP、分页和平台类型映射留给后续接口模块。`disabled` 用于提交锁定。

Token 不写入浏览器持久存储。无有效选择、查询中或失败时不可读取可提交目标；上游变更、注销或卸载使旧请求失效。
