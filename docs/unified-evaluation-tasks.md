## 本轮可用功能

- 全部 / 单任务 / A/B 实验标签；评测集、评估器、执行状态表头筛选，时间排序。
- 发起评测统一弹窗，共用数据和评估器选择；A/B 增加第二个智能体版本。
- 三步评估器引导，按实际样本期望推荐，展示理由并确认选择。
- 单任务 POST /evaluations；A/B POST /run-comparisons；不拦截或模拟返回。
- 勾选静态分析后 POST /evaluations/skill-analysis，保存后端报告 ID，从任务打开对应报告并使用现有复核功能。
- 创建静态分析失败不会伪装为成功，也不会撤销已经提交的用例运行。
