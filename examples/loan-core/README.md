# 贷款核心专项交付数据

当前v3测评集位于src/agentgate/demo/loan-core-datasets.json，共3集、36样本、42轮。专项评估器定义位于同目录loan-core-evaluators.json；启动器使用接收方配置的模型初始化，不携带密钥。

## 历史验收记录（只读）

可直接打开 [历史报告](history/index.html)。history/2026-10-07-summary.json与9个results.json保存2026-10-07真实DeepSeek v4 Pro验收：使用旧v2，每集8样本，共72样本，67通过、5失败。失败依据保留；已移除Judge原始请求和响应。模型测试使用合成客户，不是生产审批。

这份旧 HTML/JSON 报告本身不导入任务列表，也不代表 v3 或接收方模型的结果。新增的统一历史包按下述方式导入。需要新结果时运行 scripts/run-loan-core-evaluations.py；新任务有独立 ID，并使用本机最新发布的测评集版本。

## 统一任务历史包（2026-10-09）

`src/agentgate/demo/loan-history.json.gz` 保存原 6197 环境的 31 个单任务和原 7197 环境的 12 个 A/B 任务。A/B 包含 3 个连通性检查和 9 个每侧 20 样本的完整对比。总计 43 个任务、55 次运行（49 完成、6 失败）、391 条样本 Trace、1776 条评估结果及 1 份 Skill 静态分析报告。失败是原始历史事实，不改成通过。

数据使用合成贷款客户。包中保留任务 ID、原时间、固定的测评集/评估器/目标定义、分数、评审依据和已有 Trace；历史详情不依赖接收方重新配置同版本评估器。没有导出密钥库、模型连接环境文件或可用会话令牌；部分旧快照保留不含密钥内容的凭据引用 ID，以维持快照摘要。历史包不包含发送端磁盘附件、独立 Trace Server 的原始存储或浏览器本地人工标注。

启动方法见仓库 README。标准行外 SQLite 启动流程自动调用 `scripts/seed-loan-evaluators.py` 导入缺失记录。在已安装依赖且只需查看历史时，无需模型密钥：

```bash
.venv/bin/python scripts/start-integration.py --no-browser
```

打开 http://127.0.0.1:5197/，选择“行外 Login”→“测评任务”，使用“全部 / 单任务 / A/B试验”切换。列表默认“全部时间”，历史保留原始日期；选择近 7 天或近 30 天后，只显示该范围内的记录。仅查看历史不会执行模型或产生模型费用。运行新的贷款任务仍须配置自己的模型连接并启动贷款服务。

导入在事务中完成：只添加缺失行，保留已有名称及归属；遇到同 ID 的不同不可变证据会整体拒绝，不覆盖数据。每个历史包用 SHA-256 记录已导入状态，因此重复启动不产生重复记录，用户删除的任务也不会在下次启动被恢复。行内模式和 MySQL 不自动导入。

压缩包约 4.4 MB，SHA-256：`29bf2c07dd996e899d808616a73cef21d4c85d5947cc1118eb376fd944f0f950`。这是固定历史交付包，不会自动收集接收方后来产生的任务；新增本机记录仍需自行备份 `runtime/`。

本机合并后的入口是 http://127.0.0.1:7197/#/tasks，数据库为 `runtime/loan-ab-acceptance.db`。原 6197 库未修改；合并前两个库的 SQLite 一致性备份保存于 `runtime/history-merge-20261009/source-0.db` 和 `source-1.db`，不随源码分发。
